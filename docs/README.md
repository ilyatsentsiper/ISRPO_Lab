\# Техническая документация модуля main.py



\## Общее описание решения

Модуль содержит набор функций для математических вычислений. Программа написана с использованием стандартных средств Python без привлечения сторонних библиотек.



\## Подробное описание функций



\### 1. Функция `area(r)`

\* \*\*Назначение:\*\* Нахождение площади.

\* \*\*Пример вызова:\*\*

```python

res = area(1)

print(res) # 3.1415

```



\### 2. Функция `circumference(r)`

\* \*\*Назначение:\*\* Нахождение длины окружности.

\* \*\*Пример вызова:\*\*

```python

res = circumference(10)

print(res) # 314.15

```
